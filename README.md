 # Student Management System (Python)

A menu-driven Student Management System built using  Python.


default login user id  cyberadmin
default login password  cyberadmin

## Features

- Login Authentication
- Add Student
- Delete Student
- Search Student
- Update Student
    - Name
    - Roll Number
    - Branch
    - Marks
- Display Topper
- Sort Students by Marks
- Save Student Data to File

- OOP
- Classes & Objects
- Functions
- Exception Handling
- File Handling
- List of Dictionaries
- Linear Search
- Bubble Sort
